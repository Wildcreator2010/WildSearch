WildSearch 1.0.2 是首个通过 GitHub Releases 分发的正式版本，包含 1.0.1 的全部稳定性修复。

### 自动更新
- 更新源接入正式仓库，启动时与回到前台时自动检查，6 小时内最多一次；设置页可手动检查或关闭
- 检查、下载、安装全程可取消；关闭下载弹窗仅隐藏界面，下载继续
- APK 下载使用独立超时（连接 15 秒、读取 60 秒、总计 10 分钟），并校验文件大小、SHA-256 与 APK 文件头
- 未授予「安装未知应用」权限或调起安装器失败时，保留已校验 APK，重试无需重新下载

### 搜索与设置
- API Key 保存前统一校验：允许清空，拒绝内部空白和非 ASCII 字符；仅在持久化成功后提示已保存
- 搜索、更新检查、下载均支持取消，旧请求结果不会覆盖新状态
- 成功响应上限 8 MiB、错误响应 256 KiB；超限时明确报错，不解析截断 JSON；原始响应预览限制 256 KiB
- 版本比较遵循 SemVer 预发布优先级，忽略构建元数据

### 安装说明
- 支持 Android 8.0（API 26）及以上。
- 如果你安装的是此前用 debug 密钥构建的 1.0.1，正式签名不同，系统会拒绝覆盖安装；请先记录需要的设置，再卸载旧版安装本版本。此后同一正式签名的版本可直接覆盖升级，并保留数据。
